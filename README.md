# Portfólio Pessoal — Pedro Souza

## Sobre o projeto

Protótipo do meu portfólio pessoal, desenvolvido no Figma para a disciplina de **Design de Experiência e Prototipação**. O objetivo é apresentar minha trajetória, minhas habilidades e os projetos que desenvolvi na área de desenvolvimento de software.

## Estrutura

- **Apresentação:** estudante de Análise e Desenvolvimento de Sistemas no Ceuma e participante do Oxigeny Hub Ceuma.
- **Stacks / habilidades:** Python, JavaScript, HTML, CSS, Git e GitHub, Figma, UX Design e Portugol.
- **Projetos:** Por Perto, Organiza Aí e Calculadora Modular.
- **Página individual do projeto:** ao clicar em um projeto, o usuário acessa uma página com o problema, a solução, o processo, o papel e as ferramentas usadas.

## Identidade visual

- Tema escuro com destaque em verde.
- Tipografia sem serifa, com títulos grandes e textos de apoio em cinza.
- Layout desktop de 1440 px.
